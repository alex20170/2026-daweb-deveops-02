# Control de versiones y CI/CD - Parte II

Este repositorio recoge el trabajo realizado para automatizar el ciclo de vida de una aplicación Flask usando control de versiones con Git/GitHub, contenedores Docker, publicación en DockerHub y despliegue continuo en una instancia EC2 de AWS mediante GitHub Actions.

---

## 1. Preparación del entorno de desarrollo

En la máquina de trabajo (VM):

- Reinicio de servicios necesarios para Docker y red.  
- Creación y uso de un entorno virtual de Python.  
- Instalación de dependencias de la aplicación.
